# Setup

1. Create the special profile repository: `00tatheer00/00tatheer00`.
2. Copy this repository's contents into that repository.
3. Keep `README.md`, `assets/`, `scripts/`, `requirements.txt`, and `.github/`.
4. Push to GitHub.
5. In **Actions**, run **Update GitHub Profile** once manually.

The profile uses local custom SVG artwork plus live GitHub/stat services. The workflow refreshes GitHub data daily.
