## About

I'm a Pakistan-based **Software Engineer and Full-Stack Developer** focused on designing, building, and shipping practical software products.

As the founder of **[Tech4Edges](https://github.com/00tatheer00/Tech4Edges-Official-Site)**, I work across product architecture, frontend engineering, backend systems, databases, and deployment. I enjoy turning complex business workflows into reliable, maintainable applications.

- **Core focus:** Full-stack development, SaaS products, business automation, and system design
- **Frontend:** React, Next.js, TypeScript, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js, PHP, Laravel, REST APIs
- **Databases:** PostgreSQL, MongoDB, MySQL, Supabase, Firebase
- **Engineering:** Authentication, RBAC, API design, CI/CD, Docker, cloud deployment
- **Based in:** Pakistan
